Анализ количества кандидатов по базам

  • Сбор статистики о количестве активных и пассивных кандидатов в профессиональных базах данных (LinkedIn, HandFlow, HeadHunter и др.).
  • Сравнение доступных кандидатов по ключевым IT-специальностям: разработчики, аналитики, тестировщики, DevOps-инженеры.
  • Определение числа кандидатов с учётом их опыта работы: junior, middle, senior.
  • Анализ желаемых условий труда кандидатов по базам.

Анализ востребованных вакансий на международном рынке

  • Изучение спроса на IT-специалистов в глобальных базах данных (AngelList, Turing, TopTal).
  • Сравнение условий работы, предлагаемых международными компаниями на рынке Узбекистана.
  • Выявление новых трендов на международном рынке.

Анализ желаемых условий труда кандидатов по базам

  • Исследование уровня заработных плат, ожидаемых кандидатами, по различным позициям и категориям опыта.
  • Сбор данных о дополнительных пожеланиях: удалённая работа, гибкий график, соцпакет.
  • Выявление приоритетов кандидатов при выборе компании: карьерный рост, корпоративная культура, возможность обучения.

Анализ условий труда компаний-конкурентов

  • Сравнение заработных плат и бонусов, предлагаемых конкурентами в регионе.
  • Изучение корпоративных программ развития сотрудников.
  • Оценка предложений конкурентов по дополнительным бенефитам (обучение, страховка, отпуск).

Прескриннинг

Прескриннинг

Прескриннинг резюме IT-специалистов по базам

  • Фильтрация резюме по ключевым навыкам.
  • Оценка релевантного опыта и соответствия заявленным позициям.

Прескриннинг резюме IT-специалистов с условиями труда

  • Отбор кандидатов, готовых к релокации, с учётом требований компании.
  • Согласование желаемых условий работы (график, зарплата).

Прескриннинг коммерческих предложений аутсорсинговых компаний, предоставляющих услуги сервиса IT

  • Сравнение условий, предлагаемых различными аутсорсинговыми компаниями.
  • Выявление оптимальных предложений по ценам и качеству услуг.

Прескриннинг BPO-специалистов по базам

  • Анализ резюме специалистов в сфере BPO (колл-центры, поддержка клиентов, продажи).
  • Оценка уровня владения иностранными языками (английский, немецкий, французский).

Прескриннинг BPO-специалистов с условиями труда

  • Поиск специалистов с желаемыми условиями занятости.
  • Проверка готовности кандидатов к удалённой работе или гибкому графику.

Прескриннинг коммерческих предложений компаний, предоставляющих услуги сервиса

  • Сбор и анализ предложений по BPO-услугам (обработка данных, техническая поддержка).
  • Оценка стоимости услуг и SLA (Service Level Agreement).
